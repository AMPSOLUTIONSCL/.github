## Quiénes somos

**AMP Solutions CL** es una empresa chilena de desarrollo de software. Construimos aplicaciones móviles, plataformas web y APIs para empresas que necesitan soluciones a medida, no plantillas.

Acompañamos el proyecto completo: levantamiento de requerimientos, desarrollo, despliegue y mantención.

<br>

## Qué hacemos

| Servicio | Descripción |
|---|---|
| **Aplicaciones móviles** | Apps Android nativas con Kotlin y Jetpack Compose. |
| **Plataformas web** | Sistemas de gestión, portales y backoffice con Next.js y React. |
| **APIs e integraciones** | Servicios REST en Node.js/TypeScript y PHP, integrados con sistemas existentes. |
| **Automatización** | Agentes de sincronización, procesos programados y herramientas internas. |
| **Infraestructura** | Despliegue, contenedores, CI/CD y mantención de ambientes productivos. |
